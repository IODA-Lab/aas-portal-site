# 한양대 AAS Archive

산업 장비 70종의 AAS 참조모델과 개발계획서, 가이던스, 시뮬레이션, 참고자료를 장비별로 모은 저장소입니다.

## 폴더 구성

```text
equipment/<장비군>/<장비>/
  개발계획서/   참조모델 개발계획서
  가이던스/     AAS 활용 가이던스
  AASX/        AASX 모델과 UML 원본
  시뮬레이션/   코드, 실행 안내, 영상 링크
  참고자료/     카탈로그, 매뉴얼, 참고 링크
tools/          여러 장비에 함께 쓰는 도구
```

파일은 장비 폴더에만 저장합니다. 아래 표는 파일을 저장하지 않고 링크만 연결합니다.
