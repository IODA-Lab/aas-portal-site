# 한양대 AAS Archive

장비별 AAS 참조모델과 관련 문서, 시뮬레이션 및 시연 영상을 모아둔 공간입니다. 관심 있는 장비를 선택해 모델의 구성과 활용 방법을 살펴보고, 필요한 자료를 내려받아 활용하실 수 있습니다.

## 장비별 자료 살펴보기

먼저 [장비군별 목록 — 29개 장비군 · 70종 장비](equipment/README.md)에서 찾으시는 장비를 선택해 주세요. 각 장비의 자료는 다음 네 가지로 나누어 안내합니다.

| 찾으시는 내용 | 살펴볼 폴더 |
|---|---|
| 장비의 모델 구성과 활용 방법 | **문서·모델** — AAS 모델, 가이던스, 개발계획서, 시나리오·데이터 정의 |
| 동작 과정과 구현 방법 | **시뮬레이션·영상** — 시연 영상, 소스 코드, 입력 데이터, 실행 안내 |
| 모델과 문서 작성에 참고한 정보 | **참고자료** — 매뉴얼, 기술 문서, 웹 자료, YouTube 링크 |
| 검증 결과와 개정 내용 | **검토·개선** — 검토표, 검사 결과, 피드백, 수정 이력 |

## 자료 유형으로 찾아보기

원하시는 자료의 종류가 정해져 있다면 아래 목록에서 바로 찾아보세요.

| 자료 유형 | 이용 안내 |
|---|---|
| [AAS 모델](resources/aasx.md) | 장비별 AASX 모델과 등록된 JSON·XML 내보내기 파일을 확인하실 수 있습니다. |
| [가이던스](resources/guidance.md) | 장비별 모델 구성과 활용 방법을 살펴보세요. 편집 가능한 원본과 PDF 등 등록된 형식을 확인하실 수 있습니다. |
| [개발계획서](resources/plan.md) | 장비별 개발 범위와 추진 계획을 살펴보실 수 있습니다. |
| [시나리오·데이터 정의](resources/scenario.md) | 동작 시나리오와 데이터 항목, 변수명, 단위, 서브모델 간 관계를 확인해 보세요. |
| [시뮬레이션·코드·실행자료](resources/simulator.md) | 구현 자료를 내려받으신 뒤, 함께 제공되는 실행 환경과 사용 방법을 먼저 확인해 주세요. |
| [영상·화면 캡처](resources/video.md) | 설명·시연 영상과 화면 캡처를 통해 장비의 동작과 모델 활용 예시를 살펴보세요. |
| [참고자료·링크](resources/reference.md) | 매뉴얼, 기술 문서, 논문, YouTube 등 원본 자료와 참고 위치를 확인하실 수 있습니다. |
| [검토·피드백·개선 기록](resources/review.md) | 검토 의견과 검사 결과, 개정 이력을 함께 살펴보실 수 있습니다. |
| [공통 양식·도구](resources/tool.md) | 여러 장비에 공통으로 사용하는 문서 양식과 변환·검색 도구를 찾아보세요. |

## 등록된 자료와 출처 확인하기

[자료 안내 및 등록 현황](resources/registration-status.md)에서 장비별 자료 수와 등록 계정을 확인하실 수 있습니다. 개별 파일의 출처와 등록 시점은 [자료별 출처 및 등록 이력](resources/registration-files.md)을 참고해 주세요.

용량이 큰 파일은 [GitHub Releases의 대용량 자료 다운로드](https://github.com/IODA-Lab/aas-portal-site/releases/tag/aas-archive-20261030)에서 받으실 수 있습니다.
