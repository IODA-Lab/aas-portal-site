# 참고자료·링크

장비의 모델과 문서를 살펴보실 때 참고할 수 있는 원본 링크를 모았습니다. 아래에서 장비를 선택하시면 참고자료의 출처와 사용 위치를 확인하실 수 있습니다. 여러 장비에 공통으로 활용되는 자료는 [공통 참고자료](reference-common.md)에서 찾아보세요.

중복을 제외한 원본 링크는 187개이며, 이 중 YouTube 링크는 10개입니다. 영상 제목과 채널은 9개에서 확인되며, 정보 확인이 제한되는 링크는 해당 자료에 표시했습니다.
