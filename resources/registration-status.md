# 자료 안내 및 등록 현황

이곳에서는 장비별 AAS 참조모델과 개발·활용 문서, 시뮬레이션, 설명·시연 영상을 살펴보실 수 있습니다. 찾으시는 자료에 따라 아래 바로가기를 이용해 주세요.

## 필요한 자료 찾기

| 살펴보고 싶은 내용 | 바로가기 |
|---|---|
| 특정 장비의 모델과 관련 자료 | [장비군별 목록에서 장비 선택하기](../equipment/README.md) |
| 장비의 동작이나 구현 과정 | [설명·시연 영상](video.md) · [시뮬레이션·실행자료](simulator.md) |
| 문서와 모델 작성에 참고한 정보 | [장비별 참고자료와 YouTube 링크](reference.md) |
| 파일의 출처와 등록 시점 | [자료별 출처 및 등록 이력](registration-files.md) |
| 용량이 큰 파일 내려받기 | [GitHub Releases](https://github.com/IODA-Lab/aas-portal-site/releases/tag/aas-archive-20261030) |

장비를 선택하시면 **문서·모델**, **시뮬레이션·영상**, **참고자료**, **검토·개선** 폴더로 이동하실 수 있습니다. 각 폴더의 자료 목록에서 파일과 출처를 확인해 주세요.
